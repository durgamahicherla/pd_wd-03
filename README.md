# PRODIGY_WD_03 — Tic-Tac-Toe Web Application

A fully functional 2-player Tic-Tac-Toe game built during my **Web Development Internship at Prodigy InfoTech**.

---

## 📌 Task Description

Build a tic-tac-toe web application using HTML, CSS, and JavaScript. Implement functions to handle user clicks, track game state, and check for winning conditions.

---

## ✨ Features

- 🎮 2-Player mode (X vs O)
- 🏆 Win detection with highlighted winning cells
- 🤝 Draw detection
- 📊 Score tracking across multiple rounds
- 🔄 New Game & Reset Score buttons
- ✨ Smooth animations & hover effects
- 📱 Fully responsive — mobile & desktop

---

## 🛠️ Tech Stack

- **HTML5** — Game structure & layout
- **CSS3** — Styling, animations, responsive design
- **JavaScript (Vanilla)** — Game logic, win detection, DOM manipulation

---

## 💡 Key Concepts Learned

- 2D array logic for win condition checking
- DOM manipulation for dynamic game updates
- Game state management (board, currentPlayer, gameActive)
- CSS animations for winner highlight effect
- Score persistence across rounds
